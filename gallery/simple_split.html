SimpleStyle1 — разбивка 4×3 (12 частей)

Оригинал 128×112 px → сетка 4 колонки × 3 строки, каждый тайл 32×37 px

Оригинал (128×112)

12 частей (по рядам)

// Загрузка: const img = new Image(); img.src = "../assets/Tiles/Style 1/SimpleStyle1.png"; // Размер одной части const TW = 32, TH = 37; // 128/4=32, 112/3≈37 // Отрисовка части #N (0—11, по рядам): function drawTile(ctx, img, n, x, y, w, h) { const col = n % 4; const row = Math.floor(n / 4); ctx.drawImage(img, col * TW, row * TH, TW, TH, x, y, w || TW, h || TH); } // Пример — все 12 частей в ряд: for (let i = 0; i < 12; i++) { drawTile(ctx, tileImg, i, i * 32, 0); }
