# Отчёт о разработке игры Flappy Bird

## Этап 1: Базовая реализация игры

### 1.1 Цель этапа
Разработать полноценный клон игры Flappy Bird с использованием Canvas 2D, реализовав核心ную механику: физику птицы, генерацию препятствий, коллизии, систему очков и базовый игровой цикл.

### 1.2 Архитектура проекта
Проект представляет собой одностраничное приложение (Single Page Application) на чистом JavaScript без использования сторонних библиотек или фреймворков. Всё содержится в одном файле `index.html`, который включает HTML-разметку, CSS-стили и JavaScript-код.

**Файловая структура проекта:**
```
game01/
├── index.html          — главный игровой файл
├── assets/
│   ├── Background/     — фоновые изображения (7 шт.)
│   ├── Player/
│   │   ├── StyleBird1/ — скины птицы стиля 1 (4 шт.)
│   │   └── StyleBird2/ — скины птицы стиля 2 (7 шт.)
│   ├── Tiles/
│   │   └── Style 1/    — текстуры труб и земли
│   ├── Money/          — спрайт монеты
│   └── Audio/          — звуковые эффекты и музыка
├── start.bat           — скрипт запуска сервера
└── server.ps1          — PowerShell-скрипт сервера
```

### 1.3 Игровой цикл
Игровой цикл реализован через `requestAnimationFrame`, обеспечивающий плавную анимацию при 60 кадрах в секунду. Основная функция `draw()` вызывается каждый кадр и выполняет:

1. **update()** — обновление состояния игры (физика, движение объектов, коллизии)
2. **syncBgMusic()** — синхронизация фоновой музыки с состоянием игры
3. **Отрисовка** — очистка канваса, рендеринг фона, земли, труб, монет, HUD и игрока

```javascript
function draw() {
    update();
    syncBgMusic();
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    // ... рендеринг всех элементов
    requestAnimationFrame(draw);
}
```

### 1.4 Параметры игрового мира
**Холст (Canvas):**
- Размер: 720 × 450 пикселей
- Соотношение сторон фиксировано: 720 / 450 = 1.6
- Адаптивная ширина под размер окна браузера с сохранением пропорций
- Реализовано через функцию `resize()`, которая вычисляет оптимальную ширину/высоту на основе `window.innerWidth` и `window.innerHeight`

**Основные константы:**
- `PIPE_SPEED = 3` — базовая скорость движения труб
- `PIPE_GAP = 150` — расстояние между верхней и нижней трубой
- `PIPE_W = 64` — ширина трубы (текстура 32px растягивается до 64px)
- `PIPE_CAP_H = 18` — высота шапки трубы
- `GROUND_H = 24` — высота земли
- `SQ = 40` — размер одного тайла земли для текстурирования
- `GRAVITY = 0.5` — сила гравитации
- `JUMP_FORCE = -8` — сила прыжка
- `BIRD_FRAME_W = 16`, `BIRD_FRAME_H = 16` — размер одного кадра птицы
- `BIRD_FRAMES = 4` — количество кадров анимации в спрайтшите

### 1.5 Физика птицы
Птица представлена объектом с координатами x, y, вертикальной скоростью velY и размером size.

**Гравитация и прыжок:**
```javascript
// Физика (выполняется каждый кадр)
player.velY += GRAVITY;        // ускорение свободного падения
player.y += player.velY;       // обновление позиции

// Прыжок (по нажатию Space или клику)
player.velY = JUMP_FORCE;      // мгновенный импульс вверх
```

**Ограничения:**
- Птица не может улететь за нижнюю границу (ограничение уровнем земли)
- Птица не может улететь за верхнюю границу (ограничение потолком)
- При столкновении с границами скорость обнуляется
- При столкновении с трубой игра переходит в состояние `gameover`

### 1.6 Система состояний игры
Игра использует конечный автомат с пятью состояниями:

- **menu** — главное меню с кнопками Играть, Магазин, Настройки
- **playing** — активный игровой процесс
- **gameover** — экран проигрыша с результатами и кнопками Рестарт/Назад
- **settings** — экран настроек с регуляторами громкости
- **shop** — экран магазина с выбором скинов и фонов

Переход между состояниями осуществляется через присвоение переменной `gameState`:
```javascript
// menu → playing
gameState = 'playing';
reset();

// playing → gameover (при коллизии)
gameState = 'gameover';
gameOverSound.play();

// gameover → playing (рестарт)
gameState = 'playing';
reset();

// gameover → menu
gameState = 'menu';
```

### 1.7 Генерация препятствий (трубы)
Трубы генерируются парами (верхняя и нижняя) с переменным интервалом.

**Логика спавна:**
```javascript
function spawnPair() {
    const minTop = 40;
    const maxTop = GAME_H - PIPE_GAP - GROUND_H - 40;
    const topH = Math.floor(Math.random() * (maxTop - minTop + 1)) + minTop;
    const bottomY = topH + PIPE_GAP;
    pipes.push({ x: GAME_W, topH, bottomY, scored: false });
}
```

- Высота верхней трубы выбирается случайно от 40 до (GAME_H - PIPE_GAP - GROUND_H - 40)
- Нижняя труба располагается на расстоянии `PIPE_GAP` от верхней
- Интервал между трубами варьируется от 60 до 260 кадров (с ускорением делится на speedMult)
- Прогрессивное ускорение: базовый интервал уменьшается со временем
- 40% шанс на короткий интервал (60–100 кадров) для более динамичного геймплея

### 1.8 Система прогрессивной сложности
Скорость игры увеличивается со временем по формуле:
```javascript
speedMult = 1 + 1.0 * Math.min(frame / 18000, 1);
```

- На старте: `speedMult = 1` (базовая скорость)
- Через 18000 кадров (5 минут при 60fps): `speedMult = 2` (максимальная скорость)
- Интервал спавна труб уменьшается обратно пропорционально speedMult
- Скорость движения труб, монет, фона и земли увеличивается пропорционально

### 1.9 Коллизии и обработка столкновений
**Столкновение с трубами** — проверка пересечения прямоугольников:
```javascript
function rectCollide(ax, ay, aw, ah, bx, by, bw, bh) {
    return ax < bx + bw && ax + aw > bx && ay < by + bh && ay + bh > by;
}
```

- Проверка столкновения с верхней трубой (x, 0, PIPE_W, topH)
- Проверка столкновения с нижней трубой (x, bottomY, PIPE_W, GAME_H - GROUND_H - bottomY)
- При столкновении: `gameState = 'gameover'`, воспроизводится звук проигрыша

**Сбор монет** — проверка пересечения окружностей:
```javascript
const dx = (player.x + player.size / 2) - coin.x;
const dy = (player.y + player.size / 2) - coin.y;
if (Math.hypot(dx, dy) < player.size / 2 + coin.r) {
    coin.collected = true;
    totalCoins++;
}
```

**Подсчёт пройденных труб:**
```javascript
if (!p.scored && p.x + PIPE_W < player.x) {
    p.scored = true;
    pipesPassed++;
}
```

### 1.10 Рендеринг графики

**Фон:**
- Выбирается из 7 доступных фоновых изображений
- Масштабируется по высоте игрового поля (GAME_H)
- Скроллится со скоростью 50% от скорости труб
- Рисуется в цикле для бесшовной прокрутки

**Трубы:**
- Тело трубы: текстура 32×179 растягивается до 64×высота
- Верхняя труба использует текстуру `pipe_body_180.png` (перевёрнутую)
- Нижняя труба использует текстуру `pipe_body.png`
- При ненайденной текстуре — серый прямоугольник-заглушка

**Земля:**
- Зелёная заливка `#2d7a2d` под текстурой
- Текстура `TileStyle1.png` (280×24) тайлится сегментами по 40px
- Двухчастный drawImage при пересечении правого края текстуры для бесшовного тайлинга

**Птица:**
- Спрайтшит 64×16 с 4 кадрами по 16×16
- Анимация продвигается только при прыжке (механизм `birdFlapTimer`)
- На gameover анимация замирает на последнем кадре
- Выбор скина из 11 доступных через магазин

**HUD (интерфейс во время игры):**
- Счётчик монет (спрайт + число) в правом верхнем углу
- Счётчик пройденных труб крупным шрифтом

### 1.11 Экран Game Over
При проигрыше отображается:
- Полупрозрачный тёмный оверлей (`rgba(0,0,0,0.5)`)
- Зелёная рамка с заголовком "GAME OVER"
- Время игры в формате `м:сс` или `ч:мм:сс`
- Количество пройденных труб
- Две кнопки: "Рестарт" (слева) и "Назад" (справа)
- Фон и земля останавливаются (не скроллятся)

## Этап 2: Магазин, настройки и аудио

### 2.1 Цель этапа
Реализовать систему монет, магазин скинов и фонов, настройки звука и музыки, панель читов для отладки, а также персистентное сохранение всех данных через localStorage.

### 2.2 Система монет и сохранений
**Монеты:**
- Начисляются за сбор монет во время игры
- Отображаются в HUD во время игры
- Отображаются в магазине для покупок
- Сохраняются в `localStorage` через `localStorage.setItem('totalCoins', totalCoins)`
- Загрузка при старте: `localStorage.getItem('totalCoins') || 0`

**Персистентность данных:**
Все пользовательские данные хранятся в `localStorage` и восстанавливаются при загрузке страницы:
- `totalCoins` — количество монет
- `ownedPlayers` — массив купленных скинов птицы (JSON)
- `ownedBgs` — массив купленных фонов (JSON)
- `selectedBg` — текущий выбранный фон
- `selectedPlayer` — текущий выбранный скин птицы
- `sfxVolume` — громкость звуковых эффектов
- `musicVolume` — громкость музыки

### 2.3 Магазин (экран shop)
**Структура магазина:**
- Категории: "Фон" и "Игрок" (категория "Трубы" удалена)
- Две колонки категорий слева (ширина 110px каждая)
- Панель товаров справа с областями прокрутки
- Счётчик монет в рамке в правом верхнем углу

**Карточки товаров:**
- Размер: 130×85 пикселей
- Расположение: 3 колонки с отступом 10px
- Миниатюра: 50px высотой для фонов, центрированный спрайт для скинов
- Надпись: цена (для некупленных) или "Выбрать"/"Вкл" (для купленных)
- Зелёная рамка — текущий выбранный предмет
- Белая рамка — купленный предмет
- Серая рамка — недоступный для покупки предмет

**Фоны (7 штук):**

### 2.4 Выбор и покупка скинов
Логика покупки:
```javascript
if (owned) {
    selectPlayer(p.file);     // выбрать
} else if (totalCoins >= p.price) {
    totalCoins -= p.price;     // списать монеты
    ownedPlayers.push(p.file); // добавить в коллекцию
    saveOwnedPlayers();
    selectPlayer(p.file);      // автоматически выбрать
}
```

Функция `selectPlayer(file)`:
- Обновляет `selectedPlayer`
- Сохраняет в localStorage
- Мгновенно обновляет `birdImg` из кэша `playerThumbs`

### 2.5 Настройки (экран settings)
**Регуляторы громкости:**
- "Звук" (SFX) — громкость звуковых эффектов
- "Музыка" (Music) — громкость фоновой музыки
- Дискретные значения: 0%, 25%, 50%, 75%, 100%
- Визуальные ползунки с подписанными уровнями

**Аудиоэлементы:**
- `jumpSound` — звук прыжка (flap.mp3)
- `coinSound` — звук сбора монеты
- `purchaseSound` — звук покупки
- `gameOverSound` — звук проигрыша
- `bgMusic` — фоновая музыка (зациклена)
- `buttonClickSrc` — массив из 2 звуков нажатия кнопок (выбираются случайно)

**Воспроизведение:**
- При клике на ползунок звука: случайный звук кнопки
- При клике на ползунок музыки: запуск фоновой музыки
- Все звуки используют `unlockAudio()` для активации AudioContext после взаимодействия пользователя

### 2.6 Панель читов (Cheats)
Скрытая панель для отладки, вызываемая нажатием клавиши P (или З на русской раскладке) в главном меню.

**Функции:**
- **+999 монет** — добавляет 999 монет
- **Удалить всё** — сбрасывает монеты в 0
- **Сброс магазина** — восстанавливает начальное состояние (только бесплатные предметы в коллекции)

### 2.7 Анимация в магазине
**Птица (скины):**
- Анимированный превью в карточке товара
- Циклическая смена кадра каждые 150мс
- Использует `Date.now()` для независимой от игрового цикла анимации
- 4 кадра (как и в игре), отображаются последовательно

**Монета:**
- Спрайт-шит 16×16 с 15 кадрами
- Смена кадра каждые 66мс
- Отображается в HUD, магазине и экране настроек

### 2.8 Адаптивный дизайн
Функция `resize()` обеспечивает корректное отображение на любом экране:
```javascript
function resize() {
    const ratio = GAME_W / GAME_H;
    let w = window.innerWidth;
    let h = w / ratio;
    if (h > window.innerHeight) {
        h = window.innerHeight;
        w = h * ratio;
    }
    canvas.style.width = w + 'px';
    canvas.style.height = h + 'px';
    canvas.width = GAME_W;
    canvas.height = GAME_H;
}
```

- Холст сохраняет внутреннее разрешение 720×450
- CSS-размеры подстраиваются под окно браузера
- Обработчики событий мыши корректно преобразуют координаты через `scaleX`/`scaleY`

### 2.9 Обработка ввода
**Клавиатура:**
- `Space` — прыжок (только при `gameState === 'playing'`), с защитой от автоповтора (`spacePressed` флаг)
- `Escape` — выход в меню из любого состояния
- `P/З` — открытие/закрытие панели читов (только в меню)

**Мышь:**
- Клик — прыжок (только при игре)
- Клик — взаимодействие с кнопками меню, магазина, настроек
- Движение мыши — ховер-эффекты для кнопок (подсветка)

**Хит-тест кнопок:**
```javascript
function hitTestRect(b, mx, my) {
    return mx >= b.x - b.w / 2 && mx <= b.x + b.w / 2 
        && my >= b.y - b.h / 2 && my <= b.y + b.h / 2;
}
```
Все кнопки используют центр-базированную систему координат.

### 2.10 Запуск проекта
Проект запускается через `start.bat`, который:
1. Запускает Python HTTP-сервер на порту 8080
2. Открывает браузер по адресу `http://localhost:8080`

**Важно:** Запуск через `file://` невозможен из-за CORS-ошибок при загрузке аудио и изображений, а также из-за тайнтинга канваса.

### 2.11 Технические детали реализации

**Оптимизация загрузки:**
- Все текстуры пре-загружаются при старте страницы
- Спрайтшиты птиц кэшируются в `playerThumbs` для мгновенного переключения
- Фоновые изображения кэшируются в `bgThumbs`

**Обработка ошибок:**
- `play().catch(() => {})` — игнорирование ошибок воспроизведения аудио
- `drawImage` с незагруженными текстурами — проверка `complete && naturalWidth > 0`
- Все числовые операции защищены от NaN/undefined через значения по умолчанию (`|| 0`)

**Безопасность:**
- Никакие секреты или ключи не хранятся в коде
- Все данные хранятся локально в `localStorage`
